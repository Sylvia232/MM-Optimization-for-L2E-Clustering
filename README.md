# MM-Optimization-for-L2E-Clustering
The files starting with FinalSet/ FinalSims contain the code for generating the simulated data and computing ARI for all 4 methods: PAM, Trimmed KMeans, MM (our proposed method) and Mixture of t-distributions.  The file Plots_ARI is used to generate the final plots in the manuscript based on the ARI values from these files.  

Dortmund_final and KDDCUP contain the code for the real data analysis in the paper
